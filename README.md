# DiagnoseIT

Lekkie narzędzie wiersza poleceń napisane w **PowerShell**, stworzone z myślą o wsparciu zespołów IT Support / SysAdmin w błyskawicznej diagnostyce stacji roboczych i serwerów Windows.

Narzędzie automatyzuje zbieranie krytycznych parametrów środowiska (sprzęt, alokacja pamięci, łączność sieciowa, kondycja dysków oraz dziennik zdarzeń), generując czytelny raport **HTML** gotowy do załączenia w zgłoszeniu serwisowym (ticket) oraz ustrukturyzowany plik **JSON** do dalszej integracji.
